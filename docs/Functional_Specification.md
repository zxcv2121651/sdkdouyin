# 视频剪辑 SDK 功能说明文档

本 SDK 提供了一套完整的移动端短视频拍摄、剪辑、导出解决方案。以下是目前支持的核心功能清单。

## 1. 摄像采集功能 (Camera Capture)
提供工业级的相机预览与录屏能力，底层直通 NDK Camera2 API，画质更清晰，延迟更低。
*   **全屏实时预览**：支持将硬件相机数据 0 拷贝直接投射到 Android `SurfaceView` 上。
*   **前后置切换**：支持运行时无缝翻转摄像头。
*   **自定义分辨率与帧率**：支持在初始化时指定期望的输出画质（如 1080P, 60fps）。

## 2. 视频非线性编辑功能 (Video Editing / NLE)
上层通过 `VideoEditor` 模块调用，支持类似“剪映”的复杂多轨道剪辑。
*   **导入与裁剪**：支持导入本地 MP4 视频，并任意设置入点（Trim In）和出点（Trim Out）。
*   **视频切割**：支持在时间轴的任意位置将一段视频精准地一分为二（Split）。
*   **转场特效**：支持在两段视频之间插入交叉溶解 (Crossfade) 等转场效果。
*   **全局参数调节**：支持通过 `EffectManager` 设置全局的磨皮、瘦脸参数，以及叠加 LUT 滤镜调色。

## 3. 视频预览播放功能 (Video Preview)
提供给剪辑工作台的实时播放器，保证剪辑过程中的“所见即所得”。
*   **极致音画同步**：基于音频主时钟，画面自动微调，绝不掉帧、卡顿或音画分离。
*   **精准 Seek**：支持在时间轴上拖动进度条，画面能够毫秒级精准定位到对应的视频帧。
*   **播放控制**：提供播放 (Play)、暂停 (Pause)、获取当前进度等基础能力。

## 4. 视频导出与打包功能 (Video Export)
脱离屏幕刷新率限制的极速后台压制能力。
*   **硬件编码**：默认使用 Android NDK MediaCodec 硬件编码器 (支持 H.264 / H.265 / HEVC)。
*   **MP4 容器打包**：内置 AMediaMuxer，能够将编码出的视频裸流数据安全封装为通用的 `.mp4` 文件。
*   **后台无阻塞处理**：导出任务由独立的 `MessageLoop` 线程接管，完全不阻塞 UI，支持随时取消。
*   **实时进度反馈**：提供进度查询接口，方便 UI 层展示加载弹窗和进度条（0% - 100%）。

## 5. UI 交互层 (Android Jetpack Compose Demo)
工程内附带了一个高仿“剪映 / CapCut”的演示 App。
*   **暗/亮色主题切换**：支持通过全局按钮一键切换白天模式和黑夜模式。
*   **复杂组件化布局**：包含了水平滑动的时间轴轨道组件、工具栏组件。
*   **权限管理**：内置完整的相机、存储读写权限请求逻辑。
